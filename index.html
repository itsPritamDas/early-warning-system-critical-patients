About this demo: vitals are synthetically generated per scenario to illustrate how the proposed CNN-LSTM + attention architecture would behave at the bedside. The risk score is a weighted, sigmoid-squashed function of each vital's deviation and trend, standing in for the trained network's output. Attention weights show which features are currently driving the score, mirroring the interpretability layer described in Section 3.3 of the project report.
