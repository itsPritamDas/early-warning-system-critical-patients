DATA PIPELINE

Preprocessing workflow

As specified in the report.

  1. Time alignmentResample irregular measurements to a fixed hourly grid.
  2. Missing-value handlingForward-fill available history, then use training-set medians for remaining gaps.
  3. Outlier reviewFlag observations outside plausible physiological ranges for inspection.
  4. NormalizationStandardize continuous features using training-set statistics only.
  5. Window generationBuild 6–12 hour sequences with labels defined by a future prediction horizon.
